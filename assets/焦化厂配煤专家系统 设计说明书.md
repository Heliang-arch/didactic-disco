# 焦化厂配煤专家系统 设计说明书

## 1. 系统定位与总体设计

### 1.1 系统目标

本系统是焦化厂配煤生产的**决策支持与数据管理平台**，围绕"以销定配、以配保质"的核心业务，实现三大目标：

1.  **数据集中管理**：统一维护煤种字典、进厂煤质检、单仓煤质检、库存、价格、焦炭质检等配煤相关数据，打通与 MES、ERP（计划一体化/原料台账）、CGZL（采购质量）等外部系统的数据通道。
    
2.  **质量预测**：基于煤质指标与经验数学模型，推算配合煤 → 焦炭 → 化产品的质量指标，使配比方案在投产前即可预知效果。
    
3.  **配比优化**：在满足焦炭合同质量指标的约束下，自动搜索收益最大的配煤方案，并建立"预测 ↔ 实测"闭环以持续修正模型。

## 2. 焦化工艺指标体系

本章统一定义系统涉及的全部工艺指标，是后续业务规则与数学模型的基础。

### 2.1 煤质指标（单煤 / 配合煤 / 入炉煤）

| 指标 | 符号 | 工艺含义 | 对炼焦的影响 |
| --- | --- | --- | --- |
| 全水分 | Mt / M | 煤中全部水分含量（%） | 影响堆密度、耗热量与装炉量计量（干基折算） |
| 灰分 | Ad | 干基灰分（%） | 几乎全部转入焦炭，直接决定焦炭灰分，越低越好 |
| 挥发分 | Vdaf / V | 干燥无灰基挥发分（%） | 煤阶核心标志；决定化产品产率，影响焦炭强度与收缩 |
| 全硫 | St.d / S | 干基全硫（%） | 约 70% 转入焦炭，影响高炉铁水质量，越低越好 |
| 固定碳 | FC | 干基固定碳（%） | 与成焦率正相关 |
| 粘结指数 | G (GR.I) | 煤粘结惰性物质能力（0~100+） | 炼焦核心指标，决定焦炭强度的上限 |
| 胶质层最大厚度 | Y | 胶质体数量指标（mm） | 与 G 共同刻画结焦性，是强度预测的重要自变量 |
| 最终收缩度 | X | 胶质层固化后的收缩（mm） | 影响推焦顺畅与焦炭裂纹 |
| 奥阿膨胀度 | a（收缩度）/ b（膨胀度） | 胶质体膨胀特性（%） | 结焦性辅助判据，参与一期/小焦炉强度模型 |
| 镜质组最大反射率 | Rmax / R | 煤变质程度煤岩指标 | 煤种鉴别与混煤识别 |
| 焦渣特征 | CRC | 挥发分测定后焦渣形态（1~8 类） | 快速判断粘结性 |
| 反应性 / 反应后强度 | CRI / CSR | 单煤或焦炭的热态性能（%） | 焦炭在高炉内抗 CO₂ 溶损能力的核心指标 |

### 2.2 焦炭质量指标

| 指标 | 符号 | 工艺含义 | 质量方向 |
| --- | --- | --- | --- |
| 抗碎强度 | M40 / M25 | 米库姆转鼓试验后 >40mm / >25mm 粒级占比（%） | 越高越好 |
| 耐磨强度 | M10 | 转鼓试验后 <10mm 粒级占比（%） | 越低越好 |
| 反应性 | CRI | 焦炭与 CO₂ 反应失重率（%） | 越低越好 |
| 反应后强度 | CSR | 反应后焦炭转鼓强度（%） | 越高越好 |
| 灰分 / 挥发分 / 硫分 | Ad / V / S | 焦炭化学成分（%） | 越低越好（V 表征成熟度，约 1.2% 为佳） |
| 焦末含量 | JMo | 小粒级焦末比例 | 副产计量 |
| 碱金属 | K2O + Na2O | 碱金属氧化物合计 | 统计窗体派生指标，影响高炉炉况 |

### 2.3 化产品指标

| --- | --- | --- |

| 硫铵产率 | LA | 每吨干煤产硫酸铵（kg/t 级经验量纲） |

## 3. 煤炭资源管理业务

### 3.1 煤种分类体系（CoalKind）

*   煤种采用**两级树形分类**：大类（2 位编码，如"01"焦煤）→ 小类（4 位编码，如"0101"焦煤1）。
    
*   配煤结构统计按七大煤类归并：**肥煤（FM）、主焦煤（ZJ）、1/3 焦煤（J1\_3）、瘦煤（SM）、弱粘煤（RN）、瘦焦煤（SJ）、气煤（QM）**，另统计\*\*国产煤（GC）/ 进口煤（JK）\*\*比例。归类依据煤种名称关键字（含"肥"→肥煤、含"主"→主焦、含"1"且"3"→1/3 焦等）与煤种编码前两位。
    
*   编码自动递增；删除大类时级联删除全部下级小类。
    

### 3.2 煤归类（CoalToKind）

*   每一个具体进厂煤（矿点煤/合同煤）必须**归类到唯一煤种小类**，形成"煤名 → 煤种 → 煤编码"的映射，是全系统数据勾稽的桥梁。
    
*   煤编码规则：8 位 = 4 位煤种编码 + 4 位流水。
    
*   业务规则：
    
    *   煤名全库唯一；
        
    *   **删除保护**：该煤名已有进厂煤质检数据时禁止删除；
        
    *   **联动更新**：煤名变更或调整归类时，同步更新质检历史数据中的煤名与煤编码。
        

### 3.3 库存管理（CoalStock）

*   按"煤名 + 日期"逐日盘点**干基库存量**，同日重复录入即覆盖。
    
*   煤名必须存在于煤归类表，否则标红拒绝保存。
    
*   支持导入料场日报 Excel：取"煤名"与"料场结存（干）"两列，按煤名模糊匹配自动回填，未匹配行标红。
    
*   查询默认只显示有库存（>0）的最新记录，并自动合计总库存。
    
*   配比规划**不自动校验库存量**，库存可用性由选煤人员依据本模块人工保证。
    

### 3.4 价格管理（CoalPrice）

*   按"煤名 + 日期"逐日维护煤价；既可挂在单煤上，也可挂在煤种上（保存时先按煤种名匹配、再按煤名匹配）。
    
*   配比明细中同时记录\*\*财务价（CaiPrice）与到场价（DaoPrice）\*\*两个价格快照；配合煤加权成本 = Σ(价格 × 配比) / 100。
    
*   化产品价格（PriceProduct）单独按日维护：电、焦油、粗苯、硫铵、煤气、焦粉、焦丁、焦炭共 8 项，作为配比优化收益函数的价格系数。
    

### 3.5 煤质评价（CoalAssess）

*   以 PDF 文档形式按煤名归档《煤质评价》资料（供应商/煤种综合评审结论），支持上传、替换、在线预览、按"仅有库存的煤"过滤。
    
*   **设计说明**：系统未内置扣分、扣罚、分级等程序化考核算法，质量考核以人工评审文档归档方式管理。

## 4. 质检业务

### 4.1 进厂煤质检（JCM / JCMQY）

*   **数据来源**：以查询外部系统为主——MES（检验委托 + 分析值，限定"焦化煤"品名与"JS"样品类型，含批次号、发货单位、发站、合同号、过磅重量）与 ERP 原料台账视图；本地录入为辅。
    
*   **进厂煤取样（JCMQY）**：按日期批量录入当日快检指标，首屏只录 5 项：**Mt、Ad、Vdaf、St.d、G**；Y、X、b、R、CRI、CSR、价格在后续修改环节（含"送审"操作）补录。
    
*   **去重规则**："日期 + Ad + V + S + G"五项全同视为同一条记录，重复录入时询问是否替换。
    
*   **统计口径**：按煤名分组的期间统计采用**车数/重量加权平均** Σ(指标 × 权重)/Σ(权重)；单项指标为 0 或空的记录不计入该项权重。经验估重规则：车牌含"鲁"字按 10 吨/车，其余按 20 吨/车。
    

### 4.2 单仓煤质检（DCMQY）

*   煤入储煤仓后按**仓号 + 煤名 + 日期**录入化验结果，指标体系与进厂煤一致。
    
*   用途：跟踪每个仓的煤质变化，是配比录入时各仓煤质指标快照的直接来源。
    
*   同样采用"日期 + 四项指标"去重替换规则。
    

### 4.3 配合煤（入炉煤）质检（RLM）

*   记录入炉配合煤实测指标：Mt、Ad、Vdaf、St.d、G、Y、X、细度、T1~T3 温度、班次等。
    
*   **数据来源为外部（MES/ERP 检验）**，本系统不设录入界面，仅负责查询、多班平均及与配比单的挂接（见 §6.4）。
    
*   MES 侧取数条件：配合煤品名代码 + 取样点 + 焦线（1~5 线），并剔除无检验结果的采样单。
    

### 4.4 焦炭质检（PBCoke）

*   按"日期 + 炉组期号"录入：Mt、Ad、Vdaf、St.d、M40、M25、M10、焦末、CRI、CSR、焦重；同期号重复录入时询问是否替换。
    
*   MES 侧焦炭检验另含 K2O、Na2O，统计窗体派生"碱金属合计"指标。
    

### 4.5 焦炭合同指标（ContractCoke）

*   按炉组（1#2# / 3#4# / 5#6# / 7#8# 焦炉）逐日维护客户合同要求的目标指标：M40、M25、M10、CSR、CRI、Ad、V、S。
    
*   业务定位：**"以销定配"的约束来源**——配比规划与配比推算均以最新一期合同指标作为质量合格判定边界。

## 5. 数学模型

本章为系统核心，完整记录"煤 → 配合煤 → 焦炭 → 化产品"的推算链条与全部经验公式。

### 5.1 推算链条总览

```plaintext
各单煤指标 × 配比
      │  ① 加权平均
      ▼
配合煤加权指标
      │  ② 线性校正（RLMmodel：w1 × 加权值 + w2）
      ▼
入炉煤预测指标（RLM / YCCoal）
      │  ③ 分炉组回归公式（一期 / 二期 / 小焦炉）
      ▼
焦炭预测指标（M40、M25、M10、Ad、S、CRI、CSR）
      │  ④ 产率公式（各期共用）
      ▼
化产品预测指标（成焦率、LA、JY、CB）

```

### 5.2 第一步：加权平均

对配比 PB（%）加权的指标包括：Ad、V、S、G、Y、X、b、R、M、CRI、CSR、财务价、到场价。

```plaintext
加权值(X) = Σ(Xi × PBi) / ΣPBi        （规划场景 ΣPB 恒为 100）

```

结果逐项保留两位小数。

### 5.3 第二步：线性校正（RLMmodel 模型）

加权平均值与实际入炉煤化验值之间存在系统偏差（来自粉碎细度、混合均匀性、取样代表性等因素），因此设置按变量维护的校正系数表（RLMmodel）：

```plaintext
校正值 = w1 × 加权值 + w2

```

*   适用变量：Ad、V、S、G、Y、b；X、a、CRI、CSR、R、M 不校正直接透传。
    
*   系数按变量 + 日期维护，计算时取**最新一版**；查不到系数时默认 w1=1、w2=0（不校正）。
    
*   系数通过"配合煤实测（RLM）↔ 加权推算"的历史偏差回归确定，由模型管理界面维护。
    

### 5.4 第三步：焦炭质量预测公式（分炉组）

炉型与操作制度差异通过三套回归系数体现：**一期（1#2# 焦炉）、二期（3#4# 焦炉）、小焦炉试验**各用一组公式。自变量均为校正后的入炉煤指标。

#### 5.4.1 通用公式（Pattern1，用于 RLM 推算及通用场景）

```plaintext
M40 = 73.78 − 0.46·V·(100−Ad)/100 + 0.14·(G+13) + 11.5
M25 = 106.5 − 0.529·V + 0.0136·G + 0.011·Y
M10 = 5.98 + 0.23·V·(100−Ad)/100 − 0.022·(G+13) − 4
Ad焦 = Ad / [(100−V)/0.989 + 0.9] × 100
S焦  = S × 0.7 / [(100−V)/0.989 + 0.9] × 100        （0.7 = 硫转入焦炭比例）
CRI = 0.239·V − 0.0353·G − 0.035·Y + 22.5
CSR = 0.483·V + 0.011·Y + 0.413·G + 18

```

其中分母 `[(100−V)/0.989 + 0.9]` 为**干煤→焦炭质量换算系数**（挥发分烧损 + 焦油等损耗的经验折算），同时用于成焦率与灰硫浓缩计算。

#### 5.4.2 一期模型（1#2# 焦炉）

```plaintext
M40 = −3.07·V + 0.18126·G + 0.00227·b² + 161.8756
M25 = −0.0369·V + 0.04473·G + 0.0594·Y + 89.4562
M10 = −0.0314·G − 0.0666·Y + 8.91751
Ad  = 0.69335·Ad + 0.01226·V·Ad + 2.7742
S   = 0.83133·S − 0.01012·V + 0.35844
CRI = −0.089·G − 0.6096·Y + 0.24102·X + 34.8067
CSR = 3.94023·(G/Y) + 0.16445·G + 0.40192·Y − 0.1765·X + 41.0173

```

特点：引入奥阿膨胀度 b（平方项）与最终收缩度 X；CSR 含 G/Y 比值项（粘结性与胶质体数量的比例关系），Y 缺失时存在除零风险，录入环节须保证 Y 值完整。

#### 5.4.3 二期模型（3#4# 焦炉）

```plaintext
M40 = 0.027·G + 0.0948·Y − 0.073·V + 84.343
M25 = 106.5 − 0.529·V + 0.0136·G + 0.011·Y
M10 = 0.0717·V − 0.008·G − 0.068·Y + 5.474
Ad  = 0.82973·Ad + 0.00983·V·Ad + 2.14513
S   = 0.52884·S + 0.015256·S² + 0.20271
CRI = −0.039·G − 0.205·Y − 0.0006·G·Y + 0.0525·(X−Y) + 31.412
CSR = 6.2329·(G/Y) + 0.0832·G + 2.6775·Y − 0.042·X − 12.08

```

与一期差异：硫分为二次式；CRI 含 G·Y 交互项与 (X−Y) 收缩差项；CSR 的 G/Y 系数更大（该炉组对 G/Y 配比结构更敏感）。

#### 5.4.4 小焦炉试验模型

```plaintext
M40 = −0.102·V + 0.014·V·G + 0.021·(b+30) − 0.018·G·Y − 0.516·G/(b+30) + 78.723
M10 = 0.306·V − 0.084·G − 0.994·Y − 0.022·(b+30) + 19.407 − 0.96
Ad  = 6.58435·V + 0.85392·Ad² − 0.6073·V·Ad − 86.2673 + 0.5
S   = 1.024·V + 4.459·S + 9.425·S² − 0.91·S·V − 16.06 + 0.1
CRI = 0.374427·V − 0.46668·G + 0.001228·(b+30)² + 0.048874·Y·(b+40) − 0.00999·G·(b+30) + 65.13039 − 10.7
CSR = 33.7873·V − 0.41251·V·G + 11.848·G − 0.00122·G·(b+30) + 0.067865·G·Y − 998.793 + 15.35

```

特点：多元高次回归式，以 (b+30) 归一化膨胀度；含 ±0.1~+15.35 的人工修正常数（小焦炉与大生产炉之间的系统性偏差折算）。

> 所有预测结果统一保留两位小数。模型选用规则：配比种类为"一期配比"（或 1#2# 焦炉）用一期公式，"二期配比"（或 3#4# 焦炉）用二期公式，小焦炉配比用小焦炉公式。

### 5.5 第四步：化产品产率公式（各炉组共用）

化产品产率全部为挥发分 V 的**二次经验函数**：

```plaintext
成焦率 CokeRatio = 100 / [(100−V)/0.989 + 0.9]
硫铵 LA = 0.144·V − 1.8  − 0.0016·V²
焦油 JY = 1.53·V  − 19.4 − 0.026·V²
粗苯 CB = 0.144·V − 1.82 − 0.0016·V²

```

煤气（MQ）、焦粉（JF）、焦丁（JC）、电耗（Dian）无产率公式，仅在收益计算中按价格参与。

### 5.6 配比优化算法

**问题定义**：给定 n 种候选煤及其配比变动区间，在焦炭质量满足合同指标的约束下，求收益最大的配比组合。

**算法**：带约束的全枚举递归搜索（整数网格穷举）。

*   **搜索空间**：n 种煤 = n 层递归；每种煤的配比在其区间 \[下限, 上限\] 内以 **1 个百分点为步长**枚举。
    
*   **闭合约束**：ΣPB = 100，不满足的组合直接丢弃。
    
*   **推算**：满足闭合后依次执行加权平均 → RLMmodel 校正 → 按炉组选公式计算预测焦炭指标与化产品产率。
    
*   **质量约束（合格判定，七项同时满足）**：
    

```plaintext
M40 ≥ 合同值    M25 ≥ 合同值    M10 ≤ 合同值
CSR ≥ 合同值    CRI ≤ 合同值    Ad ≤ 合同值    S ≤ 合同值

```

*   **目标函数（最大化）**：
    

```plaintext
收益 = p电·Dian + p焦油·JY + p粗苯·CB + p硫铵·LA + p煤气·MQ + p焦粉·JF + p焦丁·JC

```

其中 JY/CB/LA 由产率公式算出；MQ/JF/JC/Dian 无产率数据时实际贡献为 0，目标函数实际 ≈ 焦油、粗苯、硫铵三项产值。

*   **求解规则**：遍历全部可行解，保留收益严格最大的唯一组合；无可行解时提示"焦炭不能达到合同指标，无法得出最优配比，请修改合同指标或重新选煤"。
    
*   **复杂度**：组合数 = Π(区间宽度+1)，区间开宽时计算量指数增长，属已知性能约束。
    

**设计说明（目标函数口径）**：当前目标函数为**产品端毛收益**，未扣除配煤成本（煤的加权财务价/到场价仅作展示）。因此"最优配比"的准确语义是"**焦炭质量达标前提下化产品产值最大**"，而非全成本利润最大。若未来需要真实利润寻优，应在校正后煤价基础上增加成本扣减项。

### 5.7 配煤结构统计

按煤种名称关键字把各煤配比归并为七大煤类占比（肥煤、主焦、1/3 焦、瘦煤、弱粘、瘦焦、气煤），用于配比方案的结构合理性展示。关键字独立判断，一个煤名可能命中多个类别，结果不归一化。

### 5.8 反推功能（FrmBinfer）

提供由目标反推的辅助计算：给定入炉煤指标与部分煤种，反推配合煤/单种煤指标，同样按一期/二期选择对应公式组，用于单煤置换评估与方案微调。

## 6. 配比管理业务

### 6.1 四类配比对比

| 配比类型 | 业务含义 | 使用场景 | 数据载体 |
| --- | --- | --- | --- |
| 生产配比（实际配比） | 当班实际执行的配煤方案 | 生产指挥，按 日期+炉组+班次+区号 一单 | PBSJ / PBSJDetail |
| 人工配比（预测配比） | 技术人员离线试算的方案 | 方案比选，不直接指导生产 | YCPB / YCPBDetail |
| 配比规划（优化配比） | 在人工配比基础上自动寻优 | 合同指标约束下的收益最大化 | 同 YCPB 系列 |
| 小焦炉配比（试验配比） | 实验室小焦炉炼焦验证用配比 | 新方案投产前的小试验证 | PBSJ\_X / PBSJDetail\_X |

### 6.2 生产配比（PBSJ）

*   **单据维度**：日期 + 炉组（PBKind）+ 班次（白/中/夜）+ 区号，单号规则 `SJ+yyyyMMdd+4位序号`。
    
*   **明细内容**：仓号、煤名、煤种、配比 %，以及录入时刻的**煤质指标快照**（来自单仓煤质检）与财务价/到场价。
    
*   **表头冗余**：自动汇总七大煤类结构与国产/进口煤比例。
    
*   **保存规则**：
    
    *   配比合计必须等于 100%，否则禁止预测与保存；
        
    *   **必须先预测后保存**——预测校验（含加权、校正、公式推算全部通过）是事实上的审核环节；
        
    *   同维度重复保存采用"先删后插"覆盖式变更，配比变更即以新单据生效；
        
    *   保存时联动生成同单号的配合煤预测（YCCoal）、焦炭预测（YCCoke）、化产品预测（YCProduct），实现"实际配比 + 当班预测效果"一体存档。
        
*   **查询容错**：查不到当日配比时自动回退到最近一个有配比单的日期并提示——体现"配比在未变更期间持续有效"的业务语义。
    

### 6.3 人工配比与配比规划（YCPB）

*   **人工配比**：手工录入或 Excel 粘贴各煤种比例 → 预测（校验 ΣPB=100 → 加权 → 校正 → 分炉组焦炭公式 → 化产品公式 → 配煤结构）→ 保存，单号 `YC+yyyyMMdd+4位序号`。
    
*   **配比规划**：读入某日生产配比作为候选煤清单 → 为每种煤设定配比变动区间 → 自动带出最新合同指标与产品价格 → 执行 §5.6 寻优 → 结果同样走"预测 → 保存"流程；同煤名同比例的方案已存在时不重复保存。
    
*   与生产配比的关系：人工配比是"参谋"，生产配比是"命令"；两者结构平行，共享同一套预测结果表。
    

### 6.4 配比与质检的闭环勾稽（BillID 回填机制）

这是系统实现"预测 ↔ 实测"对比的关键设计：

*   入炉煤质检（RLM）与焦炭质检（PBCoke）记录初始不带配比单号；
    
*   通过"**配合煤对应配比录入**"和"**焦炭对应配比录入**"两个功能，把某日某期的质检记录**挂接到当时执行的配比单**上（回填 BillID）；
    
*   挂接后同一界面三栏并列展示：**实测指标 ↔ 配比明细 ↔ 预测指标**，形成两段闭环：
    
    1.  前段：入炉煤实测（RLM）↔ 配合煤预测（YCCoal）——用于修正 RLMmodel 校正系数 w1/w2；
        
    2.  后段：焦炭实测（PBCoke）↔ 焦炭预测（YCCoke）——用于验证与修正分炉组回归公式；
        
*   "焦炭预测实际对比"统计窗体据此按日聚合展示预测值与实测值偏差。
    

### 6.5 小焦炉试验线

与大生产完全平行的简化闭环：**试验配比（PBSJ\_X，一天一单）→ 试验入炉煤（RLM\_X，含堆密度、细度、结焦时间）→ 试验焦炭（PBCoke\_X，含成焦率与 LJ1~LJ4 粒级分布）**。

*   采用独立的小焦炉预测公式（§5.4.4）；
    
*   配煤结构按煤种编码归并，名称含"进口"的煤种归到对应国产煤类下的进口细分；
    
*   业务定位：新配比方案**投产前**的实验室验证手段，降低大生产试错成本。

## 8. 系统管理

### 8.1 用户与权限

*   **权限模型**：用户（角色 Role）→ 用户-菜单授权表 → 菜单（2 位一级 / 4 位二级编码，树形）。
    
*   **角色语义**：Role = 0 为超级管理员，可见全部启用菜单；其余角色按授权表控制菜单可见性，授权到二级菜单，父级菜单自动带出。
    
*   **admin 保护**：内置 admin 固定拥有全部权限，不可在授权界面修改，密码不可经界面变更。
    
*   **权限粒度**：仅到"菜单可见/可用"一级，无按钮级、数据级控制。
    
*   权限分配采用整体覆盖式保存（先清空该用户全部授权再写入新授权），勾选父节点级联勾选子节点。
    

### 8.2 版本自动升级

*   管理员在"更新设置"中维护升级包地址、更新文件名与版本号；
    
*   客户端启动时比对库中版本号与本地版本文件，不一致则提示更新、写入新版本号并调用外部自动升级程序（AutoUpdate.exe），一致才进入登录。
    

### 8.3 数据备份与单位设置

*   提供数据库分离/附加式备份工具（后台维护用，无菜单入口）；
    
*   单位设置界面当前为只读展示 ERP 单位表，保存功能未启用（未完成功能）。

## 9. 设计约束、已知问题与改进建议

### 9.1 业务口径注意事项

1.  **字段借用**：生产配比单中"录入人"字段实际承载班次，"备注"字段实际承载区号；PBKind 在不同模块分别表示焦炉组或期号（"一期/二期配比"）。数据解读与报表开发时须注意。
    
2.  **入炉煤质检（RLM）无本系统录入入口**，数据依赖外部系统（MES/ERP）同步，接口稳定性是该闭环的前提。
    
3.  **配比规划不校验库存**，可行解的煤量可用性需人工确认。
    
4.  **目标函数未扣减配煤成本**（见 §5.6），寻优结果应理解为"达标前提下化产品产值最大"。
    

### 9.2 模型层面的已知问题

1.  通用公式的预测重载中 CRI 首项为 `0.239·Y`（其余各处均为 `0.239·V`），疑为历史笔误，建议核对原始回归资料后修正。
    
2.  一期/二期 CSR 公式均以 Y 为分母，Y 缺失或为 0 时产生除零异常，录入环节应强制 Y 值完整，或公式层增加保护。
    
3.  个别配比保存分支中炉区判断失效（两个分支调用同一公式组），分区号使用不同模型时该逻辑需修复。
    
4.  寻优步长固定 1 个百分点、全枚举，候选煤多、区间宽时计算量指数增长；如需更细粒度（0.5%）或更大搜索空间，应考虑启发式算法。
    

### 9.3 安全约束（现状陈述）

*   用户密码明文存储与比对；连接配置文件明文保存各生产库账号；数据库备份工具含硬编码口令与路径。以上均为现状事实，移交与部署时须按企业安全规范处理。
